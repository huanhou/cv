# My Portfolio

My personal website with a bit about me, my projects, my experience and a contact form.

🔗 **Live:** https://huanhou.github.io/cv

## Features
- Sidebar navigation that switches sections without reloading the page
- Project cards with screenshots, tech tags and links
- Resume section with education, experience, leadership and Gallup strengths
- Contact form that sends messages straight to my email (EmailJS)
- A cursor trail effect, just for fun
- Works on phones too (burger menu)

## Built with
HTML · CSS · JavaScript · EmailJS
